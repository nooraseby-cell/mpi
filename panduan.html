Panduan Siswa dan Guru

Media ini dirancang responsif: nyaman di HP, laptop, tablet, dan layar besar seperti TV 52 inci untuk pembelajaran klasikal (PID). Tombol dan teks membesar otomatis di layar sangat lebar.

Untuk Siswa

  1. Pilih kelas, lalu satu TP.
  2. Ikuti urutan: Pemantik → Materi → Eksplorasi → Kuis → LKPD.
  3. Kuis memberi umpan balik langsung. Skor 60 atau lebih menandai unit selesai.
  4. Isi nama dan kelas di LKPD, lalu tekan “Cetak / Simpan sebagai PDF”.

Untuk Guru

  • Gunakan halaman TP & ATP untuk melihat pemetaan 29 TP Fase D.
  • Di kelas, tampilkan satu halaman MPI di layar besar dan ajak siswa mencoba eksplorasi interaktifnya.
  • LKPD digital dapat dicetak untuk kerja kelompok atau dikerjakan langsung di perangkat siswa.
  • Progres disimpan lokal di perangkat (localStorage). Untuk rekap kelas, minta siswa menunjukkan skor kuis atau hasil cetak LKPD-nya.

Catatan Teknis

Situs ini statis (HTML, CSS, JavaScript saja), tanpa basis data dan tanpa login, sehingga cocok untuk GitHub Pages. Untuk menerbitkan: unggah seluruh isi folder ini ke akar repositori GitHub, lalu aktifkan GitHub Pages dari branch utama.

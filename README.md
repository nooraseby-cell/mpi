# MPI Matematika SMP

Media Pembelajaran Interaktif Matematika SMP Kelas 7, 8, dan 9.
Kurikulum Merdeka, pendekatan Pembelajaran Mendalam, satu MPI per Tujuan Pembelajaran (TP).
Media pembelajaran pribadi. Acuan TP dan ATP: MGMP Matematika SMP Kabupaten Lampung Tengah, 2026/2027, Fase D.

## Isi
- Beranda, Kelas 7/8/9, TP & ATP, Panduan
- 29 halaman MPI (satu per TP)
- Tahap pertama yang sudah diisi penuh: Kelas 7 Semester 1 (B.1, B.2, B.3, B.4) dengan materi interaktif, kuis, LKPD cetak, dan progres belajar (localStorage).
- 25 TP lainnya masih berupa kerangka dan diisi bertahap.

## Menerbitkan ke GitHub Pages
1. Unggah seluruh isi folder ini ke akar repositori `nooraseby-cell/mpi`.
2. Di GitHub: Settings > Pages > Build and deployment > Deploy from a branch > branch utama, folder `/ (root)`.
3. Situs akan tersedia di `https://nooraseby-cell.github.io/mpi/`.
